# type_script

## Angular Structural Directives

Examples of Angular's built-in control flow in `src/app/home/`:

- `@if` — show **Pass** or **Fail** based on `isPass`
- `@for` — list every name in the `students` array
- `@switch` — show a message based on `grade`

Run it:

```bash
npm install
npm start
```

Then open http://localhost:4200.
